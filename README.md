# Micronaut Serde Processor

[English](README.md) | [简体中文](README.zh-CN.md)

[`micronaut.serde.processor`](micronaut/serde/processor/module.norm) wraps the official annotation processor for Micronaut Serialization 3.1.1. A Norm application declares only the module dependency; the compiler discovers and runs the processor and links its outputs.
